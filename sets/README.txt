セットの ふやしかた（ファイルで管理する やりかた）
==================================================

※ かんたんに 済ませたいときは、アプリの
   せってい →「セットを つくる」からでも 作れます。
   このファイルは たくさん作るとき／みんなで共有するとき向けです。



1. このフォルダの中に、セット用のフォルダを作る
     例）sets/どうぶつ/

2. そこに 絵を入れる（png / jpg / webp / gif どれでもOK）
     例）sets/どうぶつ/いぬ.png
         sets/どうぶつ/ねこ.png

3. いちばん上のフォルダにある sets.js を開いて、
   SIGN_SETS に セットを ひとつ 足す

     {
       id:     "doubutsu",          // 半角英数。ほかとかぶらないように
       name:   "どうぶつ",           // 設定画面と題名に出る名前
       folder: "sets/どうぶつ/",      // 上で作ったフォルダ（末尾に / を付ける）
       voice:  "voice/doubutsu/",   // 録音した声を置くフォルダ
       items: [
         { file:"いぬ.png", name:"いぬ", yomi:"いぬ", action:"ワンワン と なく" },
         { file:"ねこ.png", name:"ねこ", yomi:"ねこ", action:"ニャー と なく" }
       ]
     }

   sets.js には コメントアウトした見本も 書いてあります。


こまかい話
----------

・title を書くと、その絵が題名になります。
    title: "sets/どうぶつ/title.png"
  書かないときは name が 赤いプレートに 文字で出ます。

・action は「出たらやること」です。結果のプレートに黄色で大きく出ます。
  読み上げも「名前 → やること」の順に読みます。

・yomi は 読み上げ用の ひらがなです。書かないと name をそのまま読みます。

・sound を書くと、そのカードが出たときに 音が鳴ります（なくてもOK）。
    sound:"sound/なにか.mp3"   … 用意した音を鳴らす
    sound:"crossing"          … 内蔵の踏切の音（合成音。ファイル不要）
  音が鳴りおわってから 読み上げが始まります。
  いまは 踏切のカードに sound/踏切.mp3 が入っています。

・絵は 正方形にちかいものが きれいに収まります。
  ちがう形でも はみ出さずに 中央に入ります。

・カードの枚数は 1枚からでも動きます。多くても大丈夫です。

・どのカードを使うかは アプリの設定画面で セットごとに 覚えます。
