録音した声の 置きかた
======================

このフォルダに mp3 を置くと、読み上げの かわりに その音声が流れます。
（先生や お子さんの声を録音して使うと、いちばん自然で あたたかい声になります）

ファイル名は カードの名前と 同じにしてください。


どのフォルダに 置くか
---------------------

セットごとに 分かれています。sets.js の voice に書いてある場所です。

  「どうろ ひょうしき」「やさしい 4つ」  →  voice/ （このフォルダの直下）
  あとから足したセット                  →  voice/<そのセットのid>/

いま どこに置けばよいかは、アプリの
  設定 → 音・読み上げ
のところに 表示されます。

こまかい話
----------

・置いたものだけが 差し替わります。無い分は これまでどおり
  ブラウザの音声合成で 読み上げます。
・中身は「とまれ。ピタッと とまる」のように、
  名前と やることを つづけて 録音すると そのまま使えます。
・スマホの ボイスメモや Windows の ボイスレコーダーで録音し、
  mp3 に書き出して ここに入れてください。
