# SLOT CHALLENGE ―― えらんで うごく ルーレット

肢体不自由特別支援学校での学習用に作った、スロット式のルーレットです。
スタートを おすと カードが 上から下へ 流れて ひとりでに 止まります。
出たカードの「やること」を みんなで やってみましょう。

**▶ つかう → https://eduwithdai.github.io/slot-challenge/**

タブレットのブラウザで ひらくだけ。インストールは いりません。
ファイルを ダウンロードして `index.html` を ダブルクリックしても 同じように動きます。

## できること

- スタートだけの かんたん操作（自動で 止まります）
- 出たカードを 読み上げ（録音した声を 入れることもできます）
- 「ふみきり」は 踏切の音が 鳴ります
- 一度 出たカードを もう出さない設定
- 道路標識いがいの セットも 作れます（設定画面から／`sets.js` から）
- 看板と ボタンの 文字も 書きかえられます
