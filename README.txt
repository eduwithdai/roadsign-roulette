SLOT CHALLENGE ―― えらんで うごく ルーレット
=============================================

つかいかた
----------
index.html をダブルクリックすると はじまります。
スタートを おすと ルーレットが まわり、ひとりでに 止まります。
出たカードの「やること」を みんなで やってみましょう。

画面の右上（うすい丸ボタン）
  歯車  … せんせい用 せってい
  矢印  … はじめから（出たカードの記録も消えます）


フォルダの中身
--------------

index.html      アプリ本体。これを開く
sets.js         セット（出すカードの一覧）の定義。ここを書きかえて増やせる
README.txt      このファイル
deploy-build.js ネットに出すときの下ごしらえ用。ふだんは使いません

assets/         アプリのイラスト部品
                  machine.png         抽選機
                  title-blank.png     看板（文字なし。文字はアプリが重ねる）
                  btn-start-blank.png スタートボタン（同じく文字なし）
                  title.png           文字入りの看板（今は使っていない控え）
                  btn-start.png       文字入りのボタン（同じく控え）
                  plate.png     結果の赤いプレート
                  sparkle.png   決まったときのキラキラ
                  arrow-left/right.png  矢印
                  app-icon.png  アイコン
                  背景.png       青空の背景

sets/           カードの絵。セットごとにフォルダを分ける
                  どうろひょうしき/  道路標識の絵
                  README.txt        セットの増やしかた

sound/          効果音
                  スタート.mp3   スタートを押した音（約1.8秒）
                  とまった.mp3   止まった音（約1.8秒）
                  踏切.mp3       「踏切」が出たときの音（約3.6秒）
                ※スタートと止まった音は index.html のはじめのほう
                  （START_SOUND / STOP_SOUND）で 指定しています。
                  カードごとの音は sets.js の sound: です。
                  ファイルを置かずに鳴らす内蔵の踏切音（sound:"crossing"）も
                  残してあります。

voice/          録音した声（任意）。入れると読み上げの代わりに流れる
                  README.txt        置きかた

素材/           元の画像や 前の版。アプリは使いません
                  イラストパーツ.png  パーツの元絵
                  生成画像1.png       最初の案
                  カラーイメージ*.webp 配色の案
                  旧イラスト/          差し替える前のイラスト
                  音の候補/            前に使っていた効果音


せってい画面で できること
--------------------------
つかう セット      … セットを 切りかえる
イラストの 文字    … 看板と ボタンの 文字を 書きかえる
セットを つくる    … この画面から セットを 作る／なおす／消す
                     「書き出す」で ファイルに保存、「読みこむ」で 取りこみ
つかう カード      … セットの中で 使うカードを えらぶ
一度 出たカード    … 出たカードを もう出さないように する
まわりかた         … 止まるまでの 長さ
音・読み上げ       … 音の入切、声の種類


セットを ふやす ふたつの やりかた
----------------------------------

① アプリの中から（かんたん）
   せってい →「セットを つくる」→「＋ 新しいセット」
   絵をえらんで 名前と やることを 入れるだけ。
   作ったセットは その機械のブラウザに 保存されます。
   ほかの機械でも使うときは「書き出す」で ファイルにして持っていき、
   むこうの機械で「読みこむ」。

② ファイルで管理（たくさん作るとき・みんなで共有するとき）
   sets フォルダに 絵を入れて、sets.js に書き足す。
   くわしくは sets/README.txt を見てください。

   ①と②は いっしょに使えます。設定画面には 両方が ならびます。


ネットに置いた版（タブレットで使うとき）
------------------------------------------
URL  https://eduwithdai.github.io/roadsign-roulette/

  ・タブレットのブラウザで ひらくだけ。ログインも インストールも いりません。
  ・作ったセットは その端末のブラウザに保存されます（端末ごと・別べつ）。
    ほかの端末にも入れるときは「書き出す」→「読みこむ」。
  ・公開されているページなので、URL を知っていれば 誰でも 見られます。

  中身を直したあと 出しなおすには
    git add -A
    git commit -m "なおしたところ"
    git push
  push すると 1〜2分で ページが 入れかわります。
